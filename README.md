# Практическая работа 1. Консольный симулятор службы доставки

Консольное приложение на Java: можно создавать заказы, выбирать способ доставки
(стандартная, экспресс, самовывоз), назначать курьеров и менять статус заказа.
Все данные хранятся только в памяти.

## Запуск

Открыть проект в IntelliJ IDEA и запустить `delivery.Main`, или из терминала:

```
javac -d out $(find src -name "*.java")
java -cp out delivery.Main
```

Нужна Java 17+.

## Структура

- `model` - заказ, позиция заказа, клиент, курьер, статусы заказа
- `shipping` - интерфейс `DeliveryMethod` и три способа доставки
- `service` - `OrderService`, логика работы с заказами
- `console` - меню, чтение ввода и вывод на экран

## Статусы заказа

Новый -> Подтверждён -> Отправлен -> Выполнен. Отменить заказ можно, пока он не отправлен.
